zen-colors playground

Zen Colors helps you create perceptual color tints, shades and scales easily

OKLCH by default · modern CSS in & out

Paste any common CSS color, explore a full series, export Tailwind-ready variables, check contrast, and copy agent-friendly JSON — all in the browser.

Scale canvas

Default playground uses all(weight) — lightest → base → darkest, including pure white and black at 100%.

Live methods

Interactive demos of .tint(), .shade(), series helpers, and named .scale() presets.

Contrast tools

WCAG reports via contrast(), readable text with fg(), and family colors with on(ratio).

Tailwind CSS export

Copy zen tN/sN keys or tick Tailwind 50…950 — ready for @theme.

@theme {
  --color-primary-t90: oklch(…);
  --color-primary-base: oklch(…);
  --color-primary-s90: oklch(…);
}

Usage

Library v · MIT

Canvas: new Color(c).all()

.tint(weight)

Lighten toward white in OKLCH by weight percent (default 50).

.shade(weight)

Darken toward black in OKLCH by weight percent (default 50).

.tints(step)

Series of tints at every step percent, including weight 100 (white).

.shades(step)

Series of shades at every step percent, including weight 100 (black).

.all(step)

Full series lightest → base → darkest. This panel uses the global header color & weight ().

.scale(weight)

Basic scale as a flat array — skips pure white/black. Uses the series step control.

.scale(weight, { preset: 'zen' })

Weight-driven keys tN / base / sN — default export vocabulary.

.scale(weight, { preset: 'tailwind' })

Fixed stops 50…950 with the base color at 500.

.contrast(against)

.fg()

Best black/white on this color as background.

.on(ratio)

Tint/shade of current color that meets the ratio.

Getting started

This playground is a static GitHub Pages demo. The npm package is the library of record.

Concepts

  • Mix space: OKLCH (perceptual lightness, stable hue)
  • Weight: integer 2–25 for scale series; single tint/shade accepts 0–100
  • all(weight): includes pure white/black at 100%
  • scale(weight): skips pure white/black; optional presets zen / tailwind
  • OKLCH object L: percent 0–100
  • Share URL: ?c= color · ?w= weight · ?mode=

API cheatsheet

Agents / browser JSON
