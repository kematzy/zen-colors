Getting started

This playground is a static GitHub Pages demo. The npm package is the library of record.

Concepts

  • Mix space: OKLCH (perceptual lightness, stable hue)
  • Weight: integer 2–25 for scale series;   single tint/shade accepts 0–100
  • all(weight): includes pure white/black at 100%
  • scale(weight): skips pure white/black; optional presets zen / tailwind
  • OKLCH object L: percent 0–100

API cheatsheet

Agents / browser JSON

v1 is client-side only (GitHub Pages). Use the mode to build query strings and copy JSON envelopes.

Ops: parse, tint, shade, all, scale, contrast, fg, on, random. See llms.txt.
